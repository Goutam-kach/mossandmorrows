# Image folder

Put every real site image in this folder: hero, products, maker/story, and social-sharing images. Use descriptive names such as `hero-crochet.webp` and `market-tote.webp`.

Then update the matching `src` and `alt` values in the root `site.config.json`. From the site config, files here use paths like `/assets/market-tote.webp`.

Current photo references in the config are temporary Unsplash URLs. Replace them with your own work before publishing.
